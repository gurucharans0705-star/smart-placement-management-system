# Smart Placement Management System

A full-stack web application developed using Flask and MySQL to automate campus placement activities.

## Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Features

- Student Registration
- Student Login
- Admin Login
- Authentication
- Session Management
- Student Dashboard

## Future Enhancements

- Company Management
- Resume Upload
- Eligibility Checker
- Placement Drives
- Application Tracking
- Notifications
- Analytics Dashboard

## How to Run

```bash
pip install -r requirements.txt
python create_admin.py
python app.py
```
